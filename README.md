# 👨🏻‍💻 Kaio Ghesa

**`Desenvolvedor de Software`**

Olá! Me chamo **Kaio Ghesa**, sou formado em Gestão de Tecnologia da Informação e atualmente curso Engenharia de Software.

Tenho experiência com desenvolvimento de aplicações utilizando **C#, .NET, JavaScript, TypeScript, React, Node.js e bancos de dados SQL/NoSQL**. Também atuo profissionalmente na área de **Segurança da Informação e IAM**, trabalhando com tecnologias como Microsoft Entra ID, Active Directory e CyberArk.

Gosto de transformar ideias em projetos funcionais e atualmente também desenvolvo soluções próprias, principalmente aplicações web e SaaS.
